# Legacy Graduation App (Archive)

Direktori ini menyimpan versi lama aplikasi Graduation Portal yang sebelumnya berada di root repository.

- Arsip dipindahkan untuk menghilangkan duplikasi kode Akademik di root.
- Ini bukan entrypoint aktif dan tidak dipetakan sebagai halaman publik.
- Implementasi Akademik aktif berada di `src/akademik/`.
- Aset root yang dipakai bersama PINTUKU (favicon dan icon) tetap berada di `/assets/`.
- Jangan mengaktifkan arsip ini tanpa audit kompatibilitas terhadap halaman, API, dan data terbaru.
