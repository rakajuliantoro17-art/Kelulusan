# SARPRASIN v2.0
# Global Store Management


## Overview

Folder `src/store` merupakan pusat pengelolaan **global application state** pada SARPRASIN v2.0.

Store berfungsi sebagai **Single Source of Truth** yang menyimpan data sementara aplikasi agar dapat digunakan oleh berbagai komponen dan halaman tanpa melakukan pengambilan data berulang.
