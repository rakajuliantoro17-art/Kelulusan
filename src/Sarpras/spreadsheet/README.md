# Spreadsheet Service

Spreadsheet Service adalah lapisan integrasi antara SARPRASIN dan Google Spreadsheet.

## Fungsi

- Sinkronisasi Spreadsheet
- Import Data
- Export Data
- Upload Batch
- Queue Request
- Cache
- Mapping Kolom
- Validasi Data
