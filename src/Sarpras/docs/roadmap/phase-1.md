# Phase 1 Roadmap
## Foundation Platform
### Sarprasin 2.0

---

# Overview

Phase 1 merupakan tahap pembangunan fondasi Sarprasin 2.0.

Target utama fase ini adalah membangun arsitektur sistem yang stabil, terdokumentasi, dan siap dikembangkan pada fase berikutnya.

Seluruh komponen inti seperti Firebase, Firestore, Authentication, Service Layer, Dashboard, Deployment, dan Dokumentasi harus selesai sebelum memasuki Phase 2.

# Acceptance Criteria

Phase 1 dianggap selesai apabila:

- Login berhasil.
- Firestore dapat digunakan.
- Dashboard tampil.
- CRUD Asset berjalan.
- Upload foto berhasil.
- Dokumentasi lengkap.
- Deploy berhasil.
- Backup berjalan.
- Migration berjalan.

---

# Risks

| Risiko | Mitigasi |
|----------|----------|
| Konfigurasi Firebase salah | Gunakan environment variables |
| Firestore Rules terlalu ketat | Uji dengan Emulator |
| Deployment gagal | Validasi Vercel sebelum release |
| Data tidak konsisten | Terapkan Validation Rules |

# Exit Criteria

# Long-Term Vision

Phase 1 membangun fondasi teknis Sarprasin 2.0 sebagai platform manajemen sarana dan prasarana berbasis cloud. Hasil dari fase ini menjadi dasar untuk pengembangan otomasi, analitik, kecerdasan buatan, dan integrasi lintas platform pada fase-fase berikutnya.
