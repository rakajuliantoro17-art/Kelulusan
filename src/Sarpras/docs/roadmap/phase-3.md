# Phase 3 Roadmap
## Intelligence Platform
### Sarprasin 2.0

---

# Overview

Phase 3 merupakan tahap implementasi Artificial Intelligence (AI), Machine Learning (ML), dan Decision Support System pada Sarprasin 2.0.

Pada fase ini sistem tidak hanya menyimpan dan menampilkan data, tetapi mulai mampu menganalisis, memprediksi, serta memberikan rekomendasi berdasarkan histori penggunaan aset dan pola operasional sekolah.

Seluruh hasil AI bersifat rekomendasi dan tetap memerlukan persetujuan pengguna sebelum diterapkan.

# Acceptance Criteria

Phase 3 dianggap selesai apabila:

- AI menghasilkan rekomendasi.
- Prediksi maintenance tersedia.
- Data Quality Score tampil.
- Dashboard AI aktif.
- Executive Analytics berjalan.
- Tidak ada AI yang mengubah data tanpa persetujuan pengguna.

---

# Risks

| Risiko | Mitigasi |
|----------|----------|
| Dataset kurang lengkap | Bangun data historis sejak Phase 2 |
| Prediksi kurang akurat | Evaluasi model secara berkala |
| Bias model | Validasi dengan pengguna |
| Performa model | Optimasi inferensi |

# Exit Criteria

Phase 3 selesai apabila:

- AI Recommendation stabil.
- Predictive Maintenance aktif.
- Executive Dashboard AI digunakan.
- Model ML terdokumentasi.
- AI hanya memberikan rekomendasi dan tidak melakukan perubahan otomatis.

# Long-Term Vision

Phase 3 mengubah Sarprasin 2.0 menjadi platform berbasis kecerdasan buatan yang mampu mendukung pengambilan keputusan melalui analisis data, prediksi, dan rekomendasi. Dengan pendekatan Human-in-the-Loop, sistem tetap menjaga akuntabilitas pengguna sekaligus memanfaatkan AI untuk meningkatkan efisiensi, kualitas data, dan efektivitas pengelolaan sarana dan prasarana sekolah.
