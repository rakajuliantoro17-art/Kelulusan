# Spreadsheet Backup Architecture
## Sarprasin 2.0

---

# Overview

Google Spreadsheet pada Sarprasin 2.0 tidak lagi digunakan sebagai database utama.

Cloud Firestore menjadi sumber data utama (Single Source of Truth), sedangkan Google Spreadsheet digunakan sebagai media backup, arsip, interoperabilitas, serta import dan export data.

Pendekatan ini memungkinkan data tetap mudah diakses oleh pengguna non-teknis tanpa mengurangi konsistensi sistem utama.

---

# Objectives

Spreadsheet digunakan untuk:

- Backup harian
- Arsip data
- Import data
- Export data
- Audit
- Laporan manual
- Integrasi Google Workspace

---

# Architecture

```
            Cloud Firestore
                    │
                    ▼
          Backup Service (n8n)
                    │
                    ▼
           Google Spreadsheet
                    │
      ┌─────────────┼─────────────┐
      ▼             ▼             ▼
  Google Drive   Executive    Import Service
                  Report
```

# Backup Strategy

Strategi backup menggunakan pendekatan:

```
Read Only Export
```

Spreadsheet tidak digunakan sebagai sumber perubahan data operasional.

Seluruh perubahan dilakukan melalui aplikasi Sarprasin.

# Restore Strategy

Spreadsheet hanya digunakan apabila:

- Firestore mengalami kegagalan
- Pemulihan data
- Audit historis
- Import ulang

Proses restore dilakukan melalui Migration Service.

---

# Synchronization Rules

Arah sinkronisasi.

```
Firestore

↓

Spreadsheet
```

Tidak dilakukan sinkronisasi dua arah pada operasional normal.

---

# Validation

Sebelum backup.

- Jumlah dokumen
- Struktur data
- Nilai wajib
- Referensi master

Setelah backup.

- Jumlah baris
- Ukuran file
- Metadata
- Integritas file

# Best Practices

- Firestore tetap menjadi sumber data utama.
- Spreadsheet hanya digunakan sebagai arsip dan backup.
- Jangan melakukan perubahan data operasional langsung di Spreadsheet.
- Backup harus terjadwal dan diverifikasi secara otomatis.
- Lakukan uji proses restore secara berkala.

---

# Long-Term Vision

Google Spreadsheet menjadi media backup dan interoperabilitas yang melengkapi Cloud Firestore. Dengan pemisahan peran yang jelas, Sarprasin 2.0 memperoleh keunggulan database modern berbasis cloud sekaligus mempertahankan kemudahan berbagi data, audit, dan pelaporan melalui ekosistem Google Workspace.
