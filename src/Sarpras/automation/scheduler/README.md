# Scheduler Automation

Scheduler bertanggung jawab menjalankan pekerjaan otomatis pada SARPRASIN.

## Fungsi

- Menjalankan pekerjaan terjadwal
- Sinkronisasi Spreadsheet
- Backup Database
- Reminder Maintenance
- Audit Harian
- Pembersihan Cache
- Pengiriman Notifikasi
- Rekap Dashboard
