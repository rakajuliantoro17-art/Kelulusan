## 1. Fungsi Folder

Folder `components/modals` bertanggung jawab untuk:

- Dialog input data
- Konfirmasi tindakan
- Preview informasi
- Upload dokumen
- Approval workflow
- Interaksi tanpa reload halaman


Seluruh modal dibuat modular agar dapat digunakan oleh:

- Dashboard
- Asset Management
- Maintenance
- Report
- Executive Dashboard
- Admin Panel
