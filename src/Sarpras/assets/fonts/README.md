## Overview

Folder ini berisi seluruh font lokal yang digunakan oleh
SMANSASOO Digital System.

Penggunaan font lokal bertujuan untuk:

- mempercepat loading aplikasi
- menjaga konsistensi desain
- mengurangi ketergantungan CDN eksternal
- mendukung penggunaan sistem pada jaringan lokal sekolah
- memastikan tampilan tetap sama pada semua perangkat
