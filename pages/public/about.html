Tentang Sarprasin 2.0

Smart School Asset Management System untuk digitalisasi pengelolaan sarana dan prasarana sekolah.

Deskripsi

Sarprasin 2.0 merupakan aplikasi manajemen aset sekolah yang membantu proses inventarisasi, pemeliharaan, pelaporan, audit, dan analisis data secara terintegrasi.

Tujuan

  • Digitalisasi inventaris sekolah.
  • Monitoring kondisi aset secara real-time.
  • Mendukung audit dan akuntabilitas aset.
  • Mempermudah pelaporan kepada pimpinan.
  • Menyediakan dashboard analitik.

Fitur Utama

📦

Inventaris

Pengelolaan aset sekolah.

🛠

Maintenance

Riwayat perawatan aset.

📈

Dashboard

Statistik dan analitik.

📷

QR Code

Identifikasi aset.

🤖

AI Analytics

Analisis data inventaris.

🔒

Keamanan

Role-based access control.

  • GitHub

  • Progressive Web App (PWA)

Pengembang

Dikembangkan sebagai sistem manajemen sarana dan prasarana digital untuk mendukung proses administrasi sekolah secara modern, efisien, transparan, dan terdokumentasi.
