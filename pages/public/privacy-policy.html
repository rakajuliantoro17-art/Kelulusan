SARPRASIN

Smart School Asset Management System

Kebijakan Privasi

Terakhir diperbarui: Juli 2026

1. Pendahuluan

SARPRASIN merupakan sistem informasi pengelolaan sarana dan prasarana SMAN 1 Sooko Mojokerto. Kebijakan privasi ini menjelaskan bagaimana sistem mengelola informasi pengguna dan data aset sekolah.

2. Data Yang Dikumpulkan

SARPRASIN dapat mengumpulkan beberapa jenis data:

  • Data akun pengguna (nama, email, role akses)
  • Data aset sekolah
  • Data lokasi dan ruangan
  • Data laporan kerusakan dan pemeliharaan
  • Riwayat aktivitas pengguna (audit log)

3. Penggunaan Data

Data digunakan untuk:

  • Pengelolaan inventaris sekolah
  • Monitoring kondisi aset
  • Penyusunan laporan sarana prasarana
  • Peningkatan keamanan sistem
  • Evaluasi pengelolaan aset sekolah

4. Keamanan Data

SARPRASIN menerapkan beberapa mekanisme keamanan:

  • Autentikasi pengguna
  • Pembatasan akses berdasarkan role
  • Audit aktivitas pengguna
  • Database terenkripsi melalui layanan cloud
  • Backup data secara berkala

5. Penyimpanan Data

SARPRASIN menggunakan layanan teknologi cloud untuk penyimpanan data aplikasi. Data digunakan hanya untuk kepentingan administrasi dan pengelolaan sarana prasarana SMAN 1 Sooko Mojokerto.

6. Akses Data

Akses terhadap data diberikan berdasarkan hak pengguna.

Role Akses
Administrator Pengelolaan penuh sistem
Staff Pengelolaan operasional
Viewer Melihat informasi tertentu

7. Cookies dan Penyimpanan Lokal

SARPRASIN dapat menggunakan penyimpanan lokal browser untuk menjaga sesi pengguna dan meningkatkan pengalaman penggunaan aplikasi.

8. Perubahan Kebijakan

Kebijakan privasi dapat diperbarui sesuai perkembangan sistem dan kebutuhan sekolah.

9. Hubungi Kami

Untuk pertanyaan mengenai privasi dan keamanan data, silakan hubungi administrator SARPRASIN.
